A five-axis post is only finished once it has run on the machine it was written for. So here's what I'd suggest for your CMS Trace100 (Morbidelli m100/200f): three days on site proving the post, with changes made on the spot, and Fusion training built around using it. A remote day covers preparation beforehand and support afterwards.

1Why prove the post on site

The base setup of a post is relatively quick. The hours go on the first real five-axis moves, because that's when you find out how the rotary axes behave on your machine: which way they turn, where the limits sit, and what the control does when a move gets near one. Done remotely, every one of those is a round of emails and a retest. At the machine it's a change to the post, a fresh output and another go straight away.

It's also the best moment to train. Your people watch the post's output run on their own machine, and see why the Fusion side has to be set up the way it is.

3Before I arrive

Post preparation

I'll start from the closest Autodesk post for your control and set it up for the Trace100: rotary axis output and limits for the nutating head, linearisation tolerance, safe retracts and repositioning moves, work offset handling, the tool change format, the machine's auxiliary functions (spindle, extraction, and any vacuum or clamping outputs the program drives), and the program header.

I'll work from the machine documentation, photos of the machine, screenshots or photos of the control, and a few programs that already run on it. I'll also need the nutating head's vector angles confirmed. If the documentation is thin, I'll need to talk to whoever commissioned the machine.

The post is supplied unencrypted and version controlled via GitHub, so you can see exactly what changed between revisions and roll back if you need to.

The time for that preparation comes from the remote day described below. I'll also plan the three days around your parts and the people being trained, using the models you send through, and that planning is included in the on-site price.

4The three days on site

Three days at your factory, starting around 9am on the first. I'll fly up from Christchurch early that morning to be there for the start.

Roughly, the days run like this:

  • Day one: checking the machine against the post. Axis directions, limits, work offsets and tool changes, with simple programs dry run before anything touches material.
  • Day two: real five-axis moves, and the changes that come out of them.
  • Day three: one or two of your own parts, programmed in Fusion start to finish and run where time allows.

Training runs alongside, with your programmer / operator. It's all about using the post, not a general Fusion course: setting up work coordinates and tool orientation for five-axis, controlling retracts and linking moves, reading the code the post puts out, and checking toolpaths in Fusion before they're posted. A lot of multi-axis crashes happen around repositioning between toolpaths, so time will be spent testing various scenarios with linking moves.

What you get from three days is a post whose code has run safely on your machine, and a programmer who has taken a part of yours from model to program with me beside them. It won't make anyone a five-axis expert, and some edge cases will only show up once you're cutting real jobs. The remote day is there for those.

Machine simulation

What I need from you

  • Photos of the machine bed, and close-ups of the spindle and the area around it
  • Screenshots or photos of the control, including the version screen, so I can see exactly what we're working with
  • Confirmation of the nutating head's vector angles
  • The 3D model of the machine, if you have one
  • The machine documentation: axis setup, travels and limits, rotary axis details, M-codes and how tool changes are configured. If the paperwork is thin, the contact details for whoever commissioned it
  • Three or four programs that already run well on the machine
  • A list of any post functionality outside the ordinary, so it's scoped before I start rather than found halfway through
  • One or two of your own parts, as models, and a Fusion tool library, a couple of weeks before the visit
  • Machine time for all three days, some material to cut, and the operator who knows the machine best on hand
  • One laptop or PC per attendee, with Fusion installed and signed in before I arrive: a reasonably recent machine with a dedicated graphics card, 16 GB of RAM at the very least (32 GB is better), and a proper three-button mouse
  • Fusion for Manufacturing licensed for each attendee. If you need licences, Cadpro can quote them*
  • A space to work when not at the machine

* Fusion is licensed per user, not per machine, and it's worth asking Cadpro which licence covers the five-axis toolpaths you plan to use.

A word on responsibility: the post is developed and tested with all care, but it's the machine operator's responsibility to verify any program is safe to run before cutting. Dry runs, single block and feed hold, every time.
